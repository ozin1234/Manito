# GROAD 인계 기준

기준일: 2026-11-23 (Asia/Seoul)

## 가져온 자료

원본 웹 체크아웃의 커밋되지 않은 최신 소스와 독립 Node API에서 174개 파일을 복사했다. `GROAD_IMPORT_MANIFEST.json`은 복사 당시 원본 파일의 상대경로·크기·SHA-256을 기록한다. 이후 Manito에서 변경한 실행 설정은 원본 해시와 달라질 수 있다.

원본 Git 기록, 기존 Sites 프로젝트 ID, 인증키, 설치된 패키지, 빌드 결과, 런타임 DB, 대형 지도 데이터는 복사하지 않았다. `apps/web/.openai/hosting.json`은 로컬 빌드용 빈 바인딩 설정이며 배포 프로젝트 ID가 없다. 새 사이트 배포에는 별도 등록이 필요하다.

연구 ZIP의 128개 파일은 `.local/groad-research`에 보관했다. 126개는 ZIP 내부 원본 manifest와 크기·해시가 일치한다. manifest 자체 2개는 비교할 별도 원본 해시가 없으므로 ZIP 전체 SHA-256을 인계 기록으로 남겼다. 원본 manifest는 더 큰 과거 묶음의 목록이며 모든 항목이 이번 ZIP에 있다는 뜻은 아니다.

## 제보 흐름

브라우저 → 웹 `/api/v1/reports` → Manito API `/v1/reports` → Manito 전용 파일·사진 저장소.

웹은 사진을 재인코딩하고 현재 GPS를 새로 측정한다. 위치 출처·정확도·시각을 API에 전달한다. API는 분류, 국내 좌표, 본문 크기, 사진 형식과 GPS 메타데이터를 검사한다. 제보의 기관 상태는 `draft` / `not_submitted`다.

공식 안전신문고 이동 링크는 자동 접수나 조치 회신을 의미하지 않는다. 관리자·기관 업무 흐름은 후속 개발 과제다.

## 지도와 데이터 분리

현재 PC의 선택형 공유 모드는 기존 OSM·Nominatim·OSRM 서비스에 조회를 요청한다. Manito API는 새 내부 키와 새 제보 볼륨을 사용하며 원본 제보 DB를 사용하지 않는다.

독립 지도 전체 스택의 Compose 파일도 인계했지만 볼륨 고정 이름과 호스트 포트를 Manito용으로 바꿨다. 대형 OSM/OSRM 데이터와 지도 DB가 포함되지 않아 새 PC에서 전체 스택을 바로 재현하는 패키지는 아니다. `services/api/scripts`의 기존 지도 구축 도구는 별도 검토 없이 자동 실행하지 않는다.

ITS 교통은 별도 키와 실제 도로선 파일이 있어야 지도 선으로 연결된다. 작은 도로선 JSON fixture는 단위 테스트 전용이며 실제 교통 데이터로 사용하지 않는다.

## AI와 연구 결과

현재 외부 AI는 선택적 제보 텍스트 요약에 사용한다. 사용자 동의와 서버 키가 없으면 규칙 기반이며 우왓도 규칙 기반이다. 실제 AI API 호출·성능 확인은 별도다.

최종 완전격자 연구는 590,016행·48개 구간, 2025 홀드아웃 206,640행·양성 189개를 사용했다. 통합 모형과 기준 모형의 로그손실 차이 95% 신뢰구간이 0을 포함해 예측력 개선을 유의하다고 판정하지 않았다. `research/evidence`의 최종 판정과 JSON을 우선한다. 이번 인계는 재학습이나 통계 검정을 재실행한 것이 아니다.

빠진 대형 중간 패널 10개는 `research/evidence/EXCLUDED_LARGE_FILES.csv`에 크기와 해시만 있다. `.joblib` 모델은 자동으로 로드하지 않았다.

## 실제 기기 확인이 필요한 사항

- Android/iPhone의 위치 권한·측정 정확도·카메라/갤러리 동작
- HTTPS 접속 및 GPS 거부 시 지도 선택 대체 흐름
- 사진 속 개인정보·번호판 처리와 관리 권한
- 운영 도메인, 외부 접속 인증, 기관 접수·회신

localhost에서 통과한 테스트를 휴대폰 검증 완료로 표시하지 않는다.
