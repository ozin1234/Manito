# K-ROAD 구현 범위

K-ROAD는 생활불편·도로·안전재난 현장 사진을 우왓과 확인하고, 위치와 공개 여부에 동의한 뒤 기록을 남기는 서비스다.

사진 선택 → Gemini와 분류·법령 자료 확인 → 필요한 선택지 확인 → GPS 또는 지도 위치 확인 → 명시적 공개 저장 → 관리자 검토·처리 이력·공개 진행 안내로 이어진다.

모든 우왓 진입 버튼은 같은 이름과 마스코트 아이콘을 사용한다. 사진을 보기 전 위험을 단정하지 않으며, 사진 관찰과 법령 적용 조건을 구분한다. 접수·조치 완료를 임의로 표시하지 않는다.

현재 기능은 사진 전용 분석, 생활불편·도로·안전재난 분류, 현장 지도, 알림음, 출처가 있는 공개 민원 목록, 기관 관리자 처리다. 확인되지 않은 기능을 서비스 설명에 넣지 않는다.
