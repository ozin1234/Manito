# K-ROAD 구현 범위

K-ROAD는 생활불편·도로·안전재난 사진을 AI가 판단하여 자체 관리자 접수함으로 전달하고 처리 과정을 확인하는 서비스다.

사진 분석·관리자 접수 동의 → 사진 선택 → Gemini와 분류·법령 자료 확인 → 필요할 때만 객관식 확인 → 비공개 관리자 접수 → 내 제보 목록·내용·처리 현황 조회로 이어진다. 위치는 선택 사항이며 없으면 위치 확인 필요로 표시한다. 설명 작성·별도 최종 확인·외부 신고 사이트 이동을 요구하지 않는다.

관리자는 별도 로그인 후 사진·AI 분류·선택 답변을 보고 담당 부서와 처리 상태를 관리한다. 내부 메모는 제보자에게 노출하지 않는다. 새 사진 제보는 공개 지도에 자동 표시하지 않는다. 기존 출처가 있는 공개 민원 자료와 이전 공개 기록은 별도로 유지한다.

우왓 진입 버튼은 오른쪽 아래 고정 버튼 하나로 통일한다. 상단·지도·안내 카드에는 중복 진입 버튼을 두지 않는다. 음성 기능 없이 알림음은 유지한다. 사진 관찰과 법령 적용 조건을 구분하며 실제 저장 성공 후에만 K-ROAD 접수 완료를 표시한다. 국가 민원 시스템 연동·공공기관 협약·현장 해결 완료를 임의로 주장하지 않는다.
