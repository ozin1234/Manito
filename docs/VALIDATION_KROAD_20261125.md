# K-ROAD 전용 구성과 우왓 진입 검증

## 변경 범위

- 서비스 화면·문서·실행 설정에서 이전 프로젝트 명칭과 사용하지 않는 사고예측·차량 경로·교통·위성 관측 기능을 제거했다. 이 저장소의 Git 기록과 별도 원본 작업 공간은 보존했다.
- 현재 사진 판독, 조건부 법령 검색, 선택 질문, 위치 확인, 공개 동의, 기관 관리와 공개 민원 출처를 유지했다. 기록 작성은 우왓의 확인 절차를 사용한다.
- 우왓 진입 버튼 이름과 SVG 마스코트를 통일했다. 최초 안내는 9초 후 사라지며, 창을 열면 하단 진입 버튼은 숨긴다. 움직임 줄이기 설정을 적용했다.
- 서버 내부 키 이름은 KROAD_API_KEY, 로컬 API 주소는 KROAD_API_URL을 사용한다. 기존 인증값은 변경하지 않으며 배포 환경에서도 새 이름을 등록해야 한다. 비밀 값은 Git에 포함하지 않는다.

## 실행 결과

- 최신 origin/main e2e059e 기준으로 비교했다.
- Node 자동 테스트 58개 통과: 사진·확인 동의·입력 검사·관리자 인증·동시 저장·법령 조회·클라우드 저장소·Origin 검사·알림음·공개 민원.
- TypeScript 검사 및 저장소 구성·인증키 패턴 검사 통과.
- Cloudflare Worker 배포 빌드 통과. 동적 import 및 플러그인 소요 시간 경고가 있으나 빌드 오류는 없다.
- 로컬 Worker에서 상태·기록·새 SVG 응답 200 확인. PC 및 390×844 화면에서 상단·하단 버튼, 동일 분석창 열기·닫기, 하단 내비게이션과의 간격을 직접 확인했다.
- 로컬 화면 검증에는 실제 Gemini 키를 넣지 않았다. 실제 운영 Gemini 연결은 배포 후 별도로 확인한다.

## 검증 한계

자동 검사와 화면 확인은 실제 현장 사진 판별 정확도, 휴대폰 GPS·카메라·알림음, 공공기관 공식 접수를 증명하지 않는다. 실제 사진 평가는 docs/evaluation의 별도 기록을 따른다.
