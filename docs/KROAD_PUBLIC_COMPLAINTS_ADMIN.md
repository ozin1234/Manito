# K-ROAD 공개 민원·기관 관리

생활불편·도로·안전재난 화면에는 춘천시와 강릉시의회 공개 게시판에서 수집한 35건의 목록이 있다. 제목·날짜·출처·수집 당시 상태만 사용하며 비공개 본문·작성자·연락처나 임의 좌표를 만들지 않는다. 출처 링크로 원문을 확인할 수 있다.

우왓에서 확인하고 공개한 현장 기록은 이 목록과 구분한다. 관리자 페이지 /admin은 별도 계정과 HttpOnly 세션 쿠키로 보호된다. 담당 부서·담당자·상태·내부 메모·변경 이력을 저장한다. 서버가 사용자와 버전을 검증하며, 관리자가 명시적으로 공개한 안내만 시민 화면에 표시한다.

운영 JSON 기록은 D1, 사진은 비공개 R2에 보관한다. 쓰기 잠금과 버전 검사를 함께 사용한다. 사진은 공식 민원 접수나 법 위반 확정이 아니며, 기관 시스템 자동 전송·회신은 연결되지 않았다.

로컬 계정 준비: node scripts/setup.mjs --admin. 비밀은 .local과 .env에만 두고 공개하거나 Git에 올리지 않는다. 운영 변수 이름과 실행 방법은 ENVIRONMENT.md와 DEVELOPMENT.md에 있다.
