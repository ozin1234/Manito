# K-ROAD 공개 자료와 기관 관리

생활불편·도로·안전재난 화면에는 춘천시와 강릉시의회 공개 게시판에서 수집한 35건의 목록이 있다. 제목·날짜·출처·수집 당시 상태를 사용하며 비공개 본문·작성자·연락처나 임의 좌표를 만들지 않는다. 출처 링크로 원문을 확인한다.

새 우왓 사진 제보는 공개 자료와 분리된 비공개 관리자 접수함에 바로 들어간다. `/admin`에 별도 계정과 HttpOnly 세션 쿠키로 로그인하면 기본 ‘사진 제보 접수함’에서 확인한다. 공개 수집 자료는 별도 탭에 유지한다. 사진·AI 유형·접수 번호·선택 답변을 보고 부서·담당자·상태·내부 메모·변경 이력을 관리한다. 서버는 인증·상태 전이·버전을 검증한다.

제보자는 비공개 접수증으로 현재 처리 상태·부서·시각과 전달용 안내를 조회한다. 관리자 계정·담당자·내부 메모·전체 변경 이력은 전달하지 않는다. 비공개 사진은 관리자 인증이 있어야 조회할 수 있다. 관리 종료는 해결 완료와 다르다.

운영 JSON 기록은 D1, 사진은 비공개 R2에 보관한다. 쓰기 잠금과 버전 검사를 사용한다. 안전신문고로 이동하거나 신고를 다시 입력하는 흐름은 없다. 공공기관이 이 관리자 사이트를 운영할 수 있는 구조이며 실제 협약·계정 발급·담당 부서 운영은 별도다. 국가 민원 시스템 자동 연계는 연결하지 않았다.

로컬 계정 준비: `node scripts/setup.mjs --admin`. 비밀은 `.local`과 `.env`에만 두고 Git에 올리지 않는다. 기존 환경변수와 저장소를 재사용하며 스키마·의존성 변경은 없다. 상세 계약은 [DIRECT_ADMIN_INTAKE.md](DIRECT_ADMIN_INTAKE.md)에 있다.
