# 우왓 사진 분석

우왓은 설명 입력 없이 사진을 분석하는 K-ROAD 도우미다. 최초 Google Gemini 전송 동의를 받은 뒤 사진을 보내고, 결과와 확인 질문을 화면 및 짧은 알림음으로 알린다.

1. 사진을 압축하고 EXIF를 제거한다.
2. 유형 기준과 공식 조문 적용 조건을 모델에 제공한다. 일반 자료는 BM25 방식으로 검색하고, 작은 사진 분류집은 모든 유형을 포함한다.
3. Gemini가 관찰, 세부 유형, 불확실성과 초안을 제안한다. 실제 검색 문서 ID인지와 출력 형식·일관성을 검증한다.
4. 모호한 부분은 짧은 선택지로 확인하고 정상·판별 불가·기타 유형을 자동 공개하지 않는다.
5. 현장 위치와 최신 초안의 공개 동의를 확인한 경우에만 저장한다. 사진·위치를 변경하거나 분석에 실패하면 이전 확인 토큰을 재사용하지 않는다.

모델은 서버의 GEMINI_API_KEY와 UWAT_MODEL을 사용한다. 기본 모델은 gemini-3.5-flash-lite다. 일시적 오류만 제한적으로 재시도하며, 실패를 임의 응답이나 자동 저장으로 바꾸지 않는다.

세부 유형·공식 조문·실사진 평가 기록은 PHOTO_CLASSIFICATION_RAG_20261124.md와 PHOTO_CLASSIFICATION_EVAL_20261124.md를 참고한다. 해당 평가의 표본·반복 호출·오류를 독립 현장 정확도와 혼동하지 않는다.
