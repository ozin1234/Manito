# 우왓 사진 분석과 관리자 접수

우왓은 설명 입력 없이 사진을 분석하는 K-ROAD 도우미다. 사진의 Google Gemini 분석과 K-ROAD 관리자 접수에 먼저 동의한 뒤 사진을 보낸다. 결과와 확인 질문은 화면 및 짧은 알림음으로 알린다.

1. 브라우저에서 사진을 압축하고 EXIF를 제거한다.
2. 유형 기준과 공식 조문 적용 조건을 모델에 제공한다. 일반 자료는 BM25로 검색하고 작은 사진 분류집은 모든 유형을 포함한다.
3. Gemini가 관찰·세부 유형·불확실성·제보 내용을 제안한다. 검색 문서 ID와 출력 형식·일관성을 서버가 검증한다.
4. 명확하면 비공개 관리자 접수함에 즉시 저장한다. 모호하면 객관식으로 필요한 사실만 확인하고 답변을 포함해 판단을 마무리한다. 정상·범위 밖·판별 불가와 API 오류를 접수 완료로 바꾸지 않는다.
5. 좌표가 있으면 함께 보내고 없으면 위치 확인 필요로 접수한다. 사진만으로 위치를 추측하지 않는다. 실제 저장 성공 후에만 접수증을 반환한다. 같은 요청 재시도는 같은 접수증을 반환한다.

모델은 서버의 `GEMINI_API_KEY`와 `UWAT_MODEL`을 사용한다. 기존 기본 모델 `gemini-3.5-flash-lite`를 유지한다. 일시적 오류와 검증 가능한 형식 오류에만 제한적으로 재시도한다. 외부 신고 사이트로 이동하지 않는다.

접수 프로토콜과 접수증 접근 권한은 [DIRECT_ADMIN_INTAKE.md](DIRECT_ADMIN_INTAKE.md)에 있다. 세부 유형·공식 조문·과거 실사진 평가는 PHOTO_CLASSIFICATION_RAG_20261124.md와 PHOTO_CLASSIFICATION_EVAL_20261124.md를 참고한다. 해당 과거 평가의 표본·반복 호출·오류는 이번 접수 흐름 검증 및 독립 현장 정확도와 구분한다.
