# 우왓 Gemini·RAG 구현 인계

기준일: 2026-11-23. Manito의 별도 제보 양식을 사진·대화 기반 우왓으로 통합했다. 기존 지도·경로·GPS 기능과 원본 GROAD 저장소는 보존한다.

## 설정과 실행

1. [Google AI Studio](https://aistudio.google.com/api-keys)에서 Google 계정으로 로그인하고 API 키를 생성한다. 프로젝트가 없다면 생성하거나 가져온다.
2. `node scripts/setup.mjs` 실행 후 루트 `.env`의 `GEMINI_API_KEY=` 뒤에 키를 입력한다. 키는 서버만 읽으며 Git에서 제외된다. `.env.example`은 빈 값만 제공한다.
3. `UWAT_MODEL=gemini-3.8-flash`가 기본 설정이다. 사용 프로젝트에서 허용되는 모델 ID로 변경할 수 있다. [공식 모델 문서](https://aistudio.google.com/docs/models/gemini-3.8-flash)는 이미지 입력과 구조화 출력을 지원한다고 명시한다.
4. `node scripts/dev.mjs`로 실행한다. 현재 PC의 지도 컨테이너를 조회용으로 공유하려면 기존 설정 후 `node scripts/dev.mjs --shared-maps`를 쓴다. 기본 웹 주소는 `http://127.0.0.1:5174/`다.
5. 키·모델 변경 후 서버를 재시작한다. 우왓의 연결 상태 확인 버튼은 실행 중인 서버 설정을 다시 조회한다.

OpenAI 키는 필요하지 않다. 새 외부 패키지 없이 서버의 Fetch API로 Gemini `generateContent`를 호출한다. 키는 `x-goog-api-key` 헤더에만 넣으며 URL·모델 프롬프트·브라우저 번들에 넣지 않는다. [공식 인증 안내](https://aistudio.google.com/docs/api-key), [REST 명세](https://aistudio.google.com/api-reference/generate-content)를 기준으로 구현했다.

## 실제 처리 흐름

탐색 메뉴는 생활불편(`living`)·도로(`road`)·안전재난(`safety`) 세 분야다. PC는 상단, 모바일은 하단에 같은 메뉴를 표시하며 지도 목록·건수·우왓 대화에 선택 분야를 반영한다. 위험지역/아차!지역/단순주의지역 표시는 분야와 별개로 유지한다. 우왓은 각 분야 안에서 사진과 대화로 열 수 있다.

`POST /v1/assistant/chat`의 선택적 `topic`은 새 대화의 분야를 정한다. 생략 시 `road`이며 기존 대화에 다른 분야를 보내면 `409 SESSION_TOPIC_MISMATCH`로 거부한다. 분야 전환 시 화면은 기존 확인 질문·토큰을 제거하고 새 대화를 시작한다. 첨부 사진·위치·AI 처리 동의는 유지한다. AI 응답과 저장 기록에도 `topic`을 반환한다. 과거 `topic` 없는 기록은 화면에서 도로로 취급하므로 기존 데이터 파일을 수정하지 않는다. 모델의 `intent=road_report`는 세 분야 모두에 쓰는 기존 API 호환 값이다. 새 환경변수나 데이터 마이그레이션은 없다. 안전재난 기록은 긴급 출동·공식 재난 경보를 대신하지 않는다.

사진·설명 → 검수 근거 BM25 검색 → Gemini 사진·대화 해석 → 서버 구조 검증 → 필요하면 질문 → 위치 확인 → 사용자 공개 동의 → Manito 지도 저장.

- 사진은 브라우저에서 최대 1280픽셀 JPEG로 다시 인코딩해 EXIF를 제거한다. 얼굴·번호판 자동 가림은 구현하지 않았다.
- RAG는 `services/api/src/knowledge/road-safety.json`의 공식 FAQ 요약과 내부 운영 기준을 검색한다. 한국어 글자 바이그램과 단어를 사용하는 BM25이며 벡터 검색·파인튜닝·실시간 웹 검색이 아니다. 검수 파일이 바뀌면 인덱스를 다시 만든다.
- 모델은 관찰, 내부 분류, 불확실성, 질문, 초안, 근거 ID를 JSON으로 제안한다. 구멍·그림자처럼 구분이 어려우면 선택지와 확인 불가 답을 허용한다. 관련 없는 질문의 범위 안내도 LLM이 문맥에 맞게 생성한다.
- 서버는 입력·JSON 형식·근거 ID·필드 길이·국내 좌표를 검사한다. 이 검사가 답변 의미의 정확성까지 보증하지는 않는다.
- 실제 저장은 별도 확인 토큰과 초안 버전, 사용자 동의가 있어야 한다. 설명·사진·위치를 바꾸면 화면의 기존 동의를 무효화한다. 중복 확인 요청은 동일 저장 결과를 반환한다.
- 키 누락·인증 실패·모델 오류·응답 미완료·429·네트워크 오류를 구분한다. 429와 서버 오류에만 한 차례 재시도하고 요청당 45초 제한을 둔다. 일반 대화를 규칙 답변으로 대체하지 않는다. 이전 직접 제보 API의 선택적 요약만 기존 규칙 요약 대체를 유지한다.
- 공식 안전신문고에는 자동 접수하지 않는다. 지도 저장 상태는 `draft` / `not_submitted`다.

## 음성과 운전 중 모드

브라우저의 SpeechRecognition과 SpeechSynthesis, AudioContext 알림음을 사용한다. Gemini 자체 음성 모델이나 상시 백그라운드 청취를 구현한 것은 아니다.

정차 상태에서 외부 AI 처리 동의·마이크·GPS 권한과 음성 재생을 준비해야 한다. 운전 중에는 사진·입력창·화면 선택 버튼을 숨기고 음성 응답이나 보류를 사용한다. 최초 요청에 현장 위치가 없으면 GPS를 측정하고 그 좌표를 유지한다. 차량이 이동해도 기존 현장 위치를 계속 덮어쓰지 않는다. 위치가 없으면 공개 저장하지 않는다.

AI 처리 중과 음성 읽기 중에는 인식을 멈춰 자기 목소리 입력을 줄인다. 확인 질문이 생기면 알림음과 질문을 읽고 인식을 재개한다. 활성 질문의 선택지·공개 동의만 제한된 규칙으로 연결하며, 나머지 발화는 LLM에 전달한다. 음성 상태는 화면에도 표시한다.

HTTPS 또는 localhost가 필요하다. 휴대폰의 일반 LAN HTTP, 브라우저별 인식 지원, 권한 거부, 자동 재생, 화면 잠금·백그라운드 제한은 별도 확인해야 한다. 운전 중 사용할 수 없으면 정차 후 이어가도록 보류한다. Android/iPhone 실제 기기는 아직 검증하지 않았다.

## API 계약

웹 경로는 `/api/v1/assistant/*`, 내부 서버는 `/v1/assistant/*`다. 웹 서버가 내부 인증을 추가한다.

| 메서드·경로 | 역할 |
| --- | --- |
| `GET status` | 제공자·모델·키 설정 유무·검색 방식·기관 연결 여부 |
| `POST chat` | `message`, 선택적 `sessionId`, `photoDataUrl`, `location`, `selection`, `drivingMode`, 필수 `allowAiProcessing:true` |
| `POST commit` | `sessionId`, `revision`, `confirmationToken`, `confirmed:true`로 최신 초안 공개 저장 |

주요 상태는 `conversation`, `needs_clarification`, `needs_location`, `awaiting_confirmation`, `saved`다. 응답에는 초안·질문·인용 근거와 위치 출처가 포함되며 비밀 키는 포함되지 않는다.

## 저장과 운영 한계

대화 세션·사진 초안은 Manito 제보 저장소의 `_assistant` 하위에 비공개 파일로 저장한다. 세션은 마지막 갱신 후 24시간이 지나면 접근이 만료된다. 만료 파일의 물리적 자동 삭제·운영 관리자 인증·이용자별 계정 권한·보관 정책은 아직 구현하지 않았다. 화면 보류 상태는 탭 안에서 유지되며 브라우저를 새로 열었을 때 초안을 복구하는 UI는 없다. 공개 운영 전 저장소 접근과 정리 정책을 추가해야 한다.

## 검증 범위

`node --run test`는 Gemini HTTP 응답을 모의로 제공해 사진 전달, 대화 맥락, RAG 근거, 확인 토큰, 저장 재요청, 관련 없는 질문의 비저장, 인증·한도·시간초과·미완료 응답을 검사한다. 사진 정확도나 실제 Gemini의 질문 품질을 입증하는 테스트는 아니다.

사용자가 제공한 키로 실제 인증과 대화 응답을 확인했다. 기본 모델 `gemini-3.8-flash`는 수요 과다 503과 시간초과가 관찰되어, 현재 PC의 `.env`는 실제 응답을 확인한 `UWAT_MODEL=gemini-3.5-flash-lite`로 설정했다. 이는 코드 기본값과 구분되는 로컬 설정이다.

실제 API에서 애매한 도로 설명의 확인 질문, 관련 없는 질문의 범위 안내, 단색 fixture 이미지의 전송과 판독 한계 응답, 초안 생성과 명시적 동의 후 격리 저장을 확인했다. 테스트 기록은 임시 저장소에서만 생성하고 삭제했으며 운영 지도에는 추가하지 않았다. 실제 현장 사진의 정확도·휴대폰 음성·비용 평가는 별도다. 다음 검증은 정답·애매한 사례·관련 없는 질문을 평가 자료로 두고 분류 정확도·부적절한 확정 비율·질문 후 수정률·응답 시간·호출 비용을 측정하는 것이다. 실제 운전 중 테스트를 요구하지 않고 정차·동승자 환경에서 먼저 확인한다.
