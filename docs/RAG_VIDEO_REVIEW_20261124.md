# 사용자 제공 RAG 영상 검토 (2026-11-24)

모델 가중치를 영상으로 재학습한 것은 아니다. 접근 가능한 영상의 자동 자막을 확인해 설계와 검증 방법을 검토했다. 자동 자막은 잘못 인식된 단어가 있을 수 있고 법령의 권위 있는 근거로 사용하지 않는다.

이번 변경에서 법령 문맥을 Gemini 판독 전에 제공하고, 국가법령정보센터 API에서 10개 조문을 확인했다. 실호출에서 모델이 법령 제목을 사진 근거 ID에 섞는 현상을 발견해 두 근거 체계를 분리했다. `gemini-3.5-flash-lite`의 기존 13장 회귀 시험 결과와 제약은 [사진 분류 RAG 기록](PHOTO_CLASSIFICATION_RAG_20261124.md)에 적었다. 이 시험은 이전에 본 사진을 재사용했으므로 새 강원 현장 사진에 대한 정확도를 입증하지 않는다.
