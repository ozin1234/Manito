# 동네 지도와 내가 보낸 민원

## 동네 지도

지도는 기본 확대 수준 14로 먼저 표시한다. 공개 민원은 느낌표, 우왓 현장 기록은 기존 위험 분류 표시를 사용한다. 분야·공개 민원 지역·검색어·자료 출처로 좁히고 장소 선택으로 다른 동네를 확대할 수 있다. 긴 공개 목록은 지도 아래에서 펼쳐 볼 수 있다.

공개 민원 35건의 원본 메타데이터와 기관 관리 자료는 변경하지 않았다. 별도 `apps/web/data/complaint-locations.json`에 제목의 장소를 확인한 11건만 연결했다. 각 항목에 제목에서 일치한 표현, 참고 좌표, 장소/지역 구분, 확인일과 OSM 객체 링크를 기록했다. 이 좌표는 관련 장소를 보여 주는 참고점이며 사고 발생 지점이나 실시간 위험을 검증한 좌표가 아니다. 장소가 불명확한 글은 임의 좌표를 만들지 않는다.

위치 자료: © OpenStreetMap contributors, ODbL 1.0. [이용 정책](https://operations.osmfoundation.org/policies/nominatim/)에 따라 공개 장소명만 한 기기·단일 순서·초당 1회 미만으로 소량 일회 조회했고 결과를 캐시했다. 앱에는 Nominatim 검색·자동완성·주기 조회 기능을 추가하지 않았다. 이후 위치 갱신은 근거와 장소를 검토한 뒤 명시적으로 수행해야 한다.

## 내가 보낸 민원

- 우왓에서 확인·공개 동의 후 저장에 성공한 응답만 이 브라우저의 접수증 목록에 추가한다. 다른 사람의 공개 기록이나 수집 민원을 내 기록으로 추정하지 않는다.
- 목록은 분야와 관계없이 모으며 카드 선택 시 현재 처리 단계, 관리자 공개 안내, 부서, 업데이트 시각을 표시한다. 창을 닫으면 선택한 카드로 초점을 돌린다.
- 새로고침과 창 복귀 시 기존 `/api/v1/case-progress`를 다시 조회한다. 조회 실패는 별도로 표시하며 이전 상태를 해결 완료로 바꾸지 않는다.
- 관리자 상태 `resolved`는 조치 완료 안내, `closed`는 관리 종료로 구분한다. 관리 종료만으로 해결을 확정하지 않는다. 현재 연동은 K-ROAD 내부 공개 처리 안내이며 기관 공식 접수·회신 연동은 별도다.
- `localStorage`의 `kroad-my-reports-v1`에는 최소 접수증 정보만 보관한다. 이것은 인증이나 비공개 자료 접근 권한이 아니다. 로그인 기반 기기 간 동기화는 아직 없으며 브라우저 데이터를 지우면 내 목록도 사라진다. 기존 목록 없이 작성자를 소급 추정하지 않는다.

## 검증

- 자동 테스트 63개 및 TypeScript 검사 통과. 위치 근거·범위·검색 필터, 접수증 복원·중복 제거·남의 자료 제외, 처리 중·조치 안내·관리 종료 구분을 포함한다.
- 로컬 Worker에서 확대된 지도와 실제 공개 민원 핀 선택·원문 링크를 확인했다.
- 내 목록의 처리 단계는 격리된 로컬 화면에서 모의 자료로 PC 및 390×844 화면을 확인했다. 운영 민원·기관 처리 상태를 테스트용으로 만들거나 바꾸지 않았다.
- 실제 사용자의 사진 제출, 브라우저 GPS와 휴대폰 촬영은 이번 화면 검증에 포함하지 않았다. 배포는 기존 사이트와 접근 범위를 유지한다.

환경변수·서버 API·DB 스키마 변경은 없다. 실행은 기존 `node --run setup`, `node --run dev`를 사용한다.
