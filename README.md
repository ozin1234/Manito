# K-ROAD

사진으로 생활불편·도로·안전재난을 확인하고 AI가 정리한 제보를 K-ROAD 관리자 접수함에 전달하는 서비스입니다. GitHub 저장소 이름은 Manito입니다.

## 운영 사이트

**[K-ROAD 바로 열기](https://k-road-manito.hydroai4.chatgpt.site/)** — 로그인 없이 접속할 수 있는 운영 주소입니다. 관리자 기능은 별도 로그인이 필요합니다.

웹과 API는 Sites의 Cloudflare Workers에 함께 배포되어 있습니다. GitHub Actions의 `Repository checks`는 코드 검사·테스트·빌드를 수행하며, 운영 배포는 별도로 진행합니다. 저장소 About의 Website와 Deployments의 `production`에서도 운영 주소를 확인할 수 있습니다. 아래 로컬 실행 주소는 개발용입니다.

## 현재 구현 방식

1. 사진 AI 분석과 관리자 접수에 먼저 동의합니다. 현장 사진을 선택하면 브라우저에서 크기를 줄이고 EXIF 위치 정보를 제거합니다. 설명 입력·마이크·음성 읽기 없이 사진만 서버로 보냅니다.
2. 서버는 생활불편·도로·안전재난의 분류 기준 13개 문서와 법령 적용 조건을 검색·구성해 Gemini에 제공합니다. 기본 모델은 `gemini-3.5-flash-lite`이며 서버의 `UWAT_MODEL`로 지정합니다.
3. Gemini가 관찰 내용, 분야, 12개 구체 유형, 불확실성과 초안을 제안합니다. 정상 사진·판별 불가·기타 유형을 구분하고, 모호하면 짧은 선택지로 확인합니다. 검색 문서 ID와 응답 형식을 서버가 검증합니다.
4. 사진 관찰과 관련 법령을 구분해 표시합니다. 조문 10개의 적용 조건을 참고하며 사진만으로 법 위반·책임·담당 기관을 확정하지 않습니다. 법령 재동기화는 국가법령정보센터 공동활용 API를 이용합니다.
5. 판단이 명확하면 추가 확인 버튼 없이 비공개 관리자 접수함에 바로 접수합니다. 모호하면 객관식 답변으로 판단을 보완한 뒤 접수합니다. 선택한 현장 위치는 포함하며, 위치가 없으면 좌표를 추측하지 않고 ‘위치 확인 필요’로 접수합니다. AI 오류·문제 없음·범위 밖은 접수하지 않습니다.
6. 결과나 확인 질문이 준비되면 화면과 짧은 알림음으로 알립니다. 실제 알림음 재생과 GPS는 브라우저 권한·사용자 조작·기기 지원에 따라 달라집니다. 운전 중 촬영·조작을 요구하지 않습니다.
7. ‘내가 보낸 제보’에서 접수 번호·분류·AI 작성 내용·사진 자동 판단 또는 객관식 확인 여부·처리 현황을 조회합니다. 비공개 접수증으로 본인의 자료만 조회하며 새 사진 제보를 일반 지도에 공개하지 않습니다. 기존 공개 민원 35건의 출처 자료는 별도로 유지합니다.
8. 관리자는 별도 로그인 후 사진 제보 접수함에서 사진·AI 판단·선택 답변을 확인하고 담당 배정·상태·메모·이력을 관리합니다. 제보자에게는 현재 상태와 전달용 안내만 보이며 내부 메모는 보이지 않습니다. 안전신문고로 이동하거나 다시 신고하지 않습니다. 실제 공공기관 협약·국가 민원 시스템 연동은 별도입니다.

## 실행 구조

- 화면: React 19, TypeScript, Vinext/Vite, SEED Design, Leaflet.
- AI/API: 기존 Node API의 입력 검사·Gemini·BM25 기반 자료 검색·동의·관리 로직을 재사용합니다.
- 운영 배포: Cloudflare Worker가 웹과 API를 함께 처리합니다. JSON 기록·대화·관리 이력·관리자 세션은 D1, 사진은 비공개 R2에 보관합니다. 큰 대화 사진은 D1 행에 넣지 않습니다.
- 동시 쓰기: D1의 만료 시간 있는 쓰기 잠금과 서버 버전 검사를 함께 적용합니다. 만료되거나 바뀐 쓰기 권한으로 저장하지 않습니다.
- 지도: 현장 지도는 공개 기록 표시·위치 선택·GPS 확인에만 사용합니다. 기본 배경은 출처·식별·캐시 정책을 지키는 OSM 타일입니다. GPS는 실제 기기 위치 권한이 필요합니다.
- 로컬: 파일 저장 방식과 별도 API 실행을 계속 지원합니다. 운영 저장소와 로컬 데이터는 별개입니다.

## 로컬 실행

Node.js 24 이상에서 `node --run setup` 후 `node --run dev`를 실행합니다. 웹 기본 주소는 `http://127.0.0.1:5174/`입니다. 사진 분석에 서버의 `GEMINI_API_KEY`가 필요합니다. 키는 `.env`에만 두고 Git에 넣지 않습니다.

- `node --run test`: API·위치·동의·관리·클라우드 저장 자동 검사
- `node --run build`: 일반 웹 빌드
- `node --run build:cloud`: Worker 빌드와 운영 산출물 준비
- `node --run check`: 저장소 기본 설정·인증정보 패턴 검사
- `node --env-file=.env services/api/scripts/sync-laws.mjs`: `LAW_API_OC`가 설정된 환경에서 법령 갱신

관리자 설정은 `node scripts/setup.mjs --admin`으로 준비합니다. 운영 비밀은 Sites 환경변수에 별도로 등록합니다. 필요한 이름은 `GEMINI_API_KEY`, `UWAT_MODEL`, `KROAD_API_KEY`, `KROAD_ADMIN_USERNAME`, `KROAD_ADMIN_PASSWORD_HASH`, `KROAD_ADMIN_SESSION_SECRET`, `KROAD_PUBLIC_ORIGIN`입니다. `LAW_API_OC`는 법령을 재동기화할 때에만 필요합니다.

실제 현장 사진의 정확도, 휴대폰 촬영·GPS·알림음은 자동 검사와 구분해 검증해야 합니다. 접수 완료는 K-ROAD 관리자 접수함에 실제 저장됐다는 뜻이며 법적 판단·국가 민원 시스템 접수·현장 해결 완료를 뜻하지 않습니다.

우왓 진입 버튼은 오른쪽 아래 고정 버튼 하나만 표시합니다. 상단·지도·안내 카드의 중복 버튼은 제거했습니다. 하단 안내는 사진을 올릴 위치를 짧게 알려 주며 최초 표시 후 사라집니다. 제보 작성은 우왓의 사진 분석·동의 절차로만 진행합니다.

동네 지도는 장소가 확인된 공개 민원을 느낌표로 표시합니다. 접수증은 이 브라우저에 보관하므로 다른 기기 동기화는 지원하지 않습니다. 최신 접수 계약과 검증 범위는 [사진 제보 직접 접수](docs/DIRECT_ADMIN_INTAKE.md), 지도 위치 근거는 [동네 지도](docs/NEIGHBORHOOD_AND_MY_REPORTS.md)에 기록했습니다.
