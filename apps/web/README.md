# K-ROAD 웹

React·TypeScript·Vinext와 SEED Design, Leaflet로 만든 사진 전용 현장 확인 서비스다. 모든 진입 버튼은 우왓 이름과 /public/uwat.svg 아이콘을 사용한다.

화면은 생활불편·도로·안전재난 공개 민원, 우왓의 사진 분석·유형·법령 근거·확인 선택지, GPS/지도 위치 확인, 공개 저장, 기관 관리자 처리로 구성된다. 현장 지도는 기록 표시와 위치 확인에만 사용한다.

전체 구현·실행·운영 설정은 저장소 루트 README.md와 docs/DEVELOPMENT.md에 있다. 기존 디자인은 유지하며 기능을 수정한다.
