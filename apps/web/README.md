# G-ROAD — 강원 AI 안전도로

> **현재 화면 (2026-11-16):** 길찾기와 주행 내비게이션 UI를 제거하고 시민 제보 중심 안전 지도로 전환했습니다. 위험지역·아차!지역·단순주의지역 제보를 사진·내용·위치와 함께 저장하고, 지도 느낌표에서 상세를 봅니다. 최근 위성 배경은 실시간 도로 촬영이 아니며, 기관 접수는 안전신문고에서 이용자가 직접 완료해야 합니다. 아래의 목적지 검색·자동 재탐색 설명은 이전 시제품의 기록입니다. 현재 기능의 실행·API 안내는 이전 패키지 `README.md`와 `docs/SEED_DESIGN.md`를 참조하세요.

기상·교통·도로·지형 데이터를 결합한 HGB 사고위험 모델과 시민 제보 흐름을 하나의 지도 UI로 연결한 반응형 PWA입니다.

## 구현 범위

- 웹/모바일 공용 반응형 PWA
- 첫 진입 G-ROAD 글자별 애니메이션·위 이동·다시 보기와 중앙 목적지 검색, 브라우저 음성 검색
- 실제 저장 모델(`HistGradientBoostingClassifier`)로 생성한 2025 홀드아웃 위험 피드
- 지도 위험등급 필터, 구간 상세, 제보 폼, AI 검증 화면
- 저장된 `.joblib`을 직접 로드하는 FastAPI 추론 서버
- G-ROAD 독립 엔진을 통한 장소 검색·자동차 경로·자체 지도 타일
- GPS 도로 맞춤 추정, 경로 이탈 감지와 자동 재탐색
- ESA WorldCover 2021 상세 위성 배경, NASA Terra MODIS 최근 관측 레이어와 ITS 교통 속도 레이어
- 지역 기상 모델의 낮·밤, 비·눈·안개에 따른 지도 표현

첫 화면에서 목적지를 입력하면 지도 위 길찾기 결과가 바로 열립니다. 마이크 검색은 지원 브라우저에서 사용자가 버튼을 누르고 권한을 허용한 경우에만 시작됩니다. 음성 인식이 지원되지 않으면 텍스트 검색을 사용할 수 있습니다.

위치 버튼을 누르면 기기에서 전달한 좌표와 정확도를 표시합니다. 오차가 80m를 넘으면 지도에는 대략적인 위치로 표시하고 자동차 경로 시작을 보류합니다. 정확한 좌표가 20초 안에 오지 않거나 위치 권한이 없으면 원인을 표시하고 다시 시도할 수 있습니다.

## 데이터 모드

배포 웹은 `public/data/risk-feed.json`을 읽습니다. 이 파일은 임의 샘플이 아니라 다음 명령으로 저장 모델을 실행해 생성합니다.

```powershell
python scripts/build_model_snapshot.py
```

화면에는 오해를 막기 위해 `2025 검증 데모`라고 표시됩니다. 실시간 운용은 VDS·AWS의 최신 2시간 지연 입력을 동일한 34개 피처 정의로 만든 후 아래 API에 전달해야 합니다.

## 실행

```powershell
npm install
npm run dev
```

지도·장소·경로 기능을 쓰려면 별도의 `groad-independent-api`를 실행하고, 웹앱 서버의 비밀 환경 변수 `GROAD_INDEPENDENT_API_URL` 및 `GROAD_INDEPENDENT_API_KEY`를 설정합니다. 로컬 개발에서는 `.env.example`을 참고하세요. 실제 배포에는 웹앱 서버에서 접근할 수 있는 독립 엔진 주소가 필요합니다.

위성사진은 ESA가 공개한 2021년 약 10m 해상도 합성 영상이며 웹앱 서버의 인터넷 연결이 필요합니다. 실시간 위성 중계가 아닙니다. 교통 속도는 별도 `ITS_API_KEY`가 독립 엔진에 설정되어야 나타납니다. ITS 도로 링크 ID와 2025 표준 도로 선형이 일치한 구간만 빨강·주황·초록 선으로 표시하며, 자동차 경로 시간에는 아직 반영되지 않습니다.

`최근 위성 관측`은 NASA GIBS의 Terra MODIS 일일 영상입니다. 요청 날짜를 화면에 표시하며 약 250m 해상도라 구름과 넓은 지형 상태를 보는 용도입니다. 현재 시각을 생중계하거나 차선·도로를 상세히 보여 주지 않습니다. 구름과 촬영 공백이 있을 수 있습니다. 낮·밤과 기상 효과는 지도 중심 좌표에 대한 Open-Meteo 최신 기상 **모델** 자료(`is_day`, 날씨 코드, 강수·적설)에 따라 바뀝니다. 이 자료는 현장 관측값이나 도로 위험 예측값이 아니며 10분마다 갱신합니다. Open-Meteo 무료 API는 비상업적 사용 조건과 출처 표시를 요구하므로 상업 서비스 전에는 이용 조건을 다시 확인해야 합니다.

2025년 상·하반기 2차 강건성 검정은 저장된 결과 파일에서 각각 Holm 보정 p=0.02295, p=0.00520으로 통과했습니다. 같은 2025 홀드아웃 자료를 나눈 검정이며 2026년 새 사고자료를 이용한 외부 검정은 별도로 필요합니다. 휴대폰용 APK를 실제 주행 앱으로 배포하려면 독립 지도·검색·경로 서버를 휴대폰에서 접근할 수 있는 HTTPS 주소로 운영하고, Android SDK에서 설치·GPS·주행 검증을 해야 합니다. 현재 로컬 주소 `127.0.0.1`은 PC에서만 열립니다.

모델 API는 별도 Python 환경에서 실행합니다.

```powershell
python -m pip install -r model-api/requirements.txt
uvicorn app:app --app-dir model-api --reload --port 8000
```

기본 모델 경로는 상위 작업공간의 `outputs/강원고속도로_사고위험_HGB_최종모델.joblib`입니다. 다른 위치를 쓰려면 `GROAD_MODEL_PATH`, `GROAD_MODEL_META_PATH`, `GROAD_VALIDATION_PATH`를 설정합니다.

## 모델 해석

- 단위: 10km 구간 × 2시간
- 용도: 절대적인 사고 예언이 아닌 상대 위험도와 점검 우선순위
- 결측치 정책: 학습과 동일한 완전사례 피처를 재현하며, 결측값을 0으로 임의 대체하지 않음
- 저장 모델 SHA-256은 화면과 `/model-info`에서 대조 가능
